SQL Generation · core/sql_gen.py

Chain: SQL_PROMPT | LLM | StrOutputParser

LangChain @traceable
↓
STEP 3
Safety · core/guardrails.py
🛡️ SQL Guardrails — validate_sql()
Three checks in order:
1. Query length ≤ 5000 chars
2. No destructive keywords (DROP / DELETE / UPDATE / INSERT / ALTER / TRUNCATE / CREATE) — word-boundary regex
3. Must start with SELECT or WITH (CTEs allowed)
Returns (is_valid, error_message). Blocked queries surface as a red error in the UI — no DB call made.
Block on fail

Database · core/supabase_client.py
🗄️ Supabase Query — run_query()
POSTs SQL to Supabase RPC endpoint /rest/v1/rpc/execute_sql via httpx.
Handles 404 (missing RPC function), non-200 errors, and JSON/string response variants.
Returns list[dict] rows. Singleton client via get_client().

End-to-End Request Flow

1
User types a question
Natural language input via st.chat_input. Sidebar sample questions can pre-fill it. Download-intent keywords are detected via regex.
app.py · _wants_download()
2
LLM generates SQL
Schema context + chat history + question fed into SQL_PROMPT. LangChain chain returns a clean SELECT / CTE query.
core/sql_gen.py · generate_sql()
3
Guardrails validate SQL
Length check → destructive keyword check → allowed operation check. Any failure returns an error; no DB call is made.
core/guardrails.py · validate_sql()
4
Query runs on Supabase
SQL POSTed to Supabase RPC execute_sql. Response parsed into list of row dicts.
core/supabase_client.py · run_query()
5
Result classified by size
Row count determines rendering mode: small / medium / large. Download intent overrides to large.
core/data_handler.py · classify_result_size()
6
LLM generates insight (non-large)
Up to 50 sample rows + total count sent to ANSWER_PROMPT. Returns structured business insight with emojis.
core/sql_gen.py · generate_answer()
7
Result rendered in chat
Table, SQL expander, download buttons, stats, and insight card rendered. Turn saved to session_state chat history.
app.py · render_result()
8
Traces logged to LangSmith
Both LLM calls are decorated with @traceable. Full input/output/latency logged to the configured LangSmith project.
core/sql_gen.py · @traceable

Response Size Logic

Size Class Row Count Table Download Stats LLM Insight
small ≤ 100 rows ✅ Inline — Expander ✅ Yes
medium 101 – 500 rows ✅ Inline CSV + Excel expander Expander ✅ Yes
large > 500 rows or download intent ⚠️ Too large CSV + Excel tabs Tab ❌ Skipped

Module Reference

app.py
Streamlit App
Entry point. Chat UI, sidebar config, session state, render helpers, orchestrates all core modules.
core/sql_gen.py
SQL + Answer Gen
SQL_PROMPT & ANSWER_PROMPT templates. generate_sql() and generate_answer() with LangSmith tracing.
core/llm.py
LLM Factory
get_llm() routes to ChatGroq or ChatGoogleGenerativeAI. fetch_groq_models() fetches live model list.
core/guardrails.py
SQL Guardrails
validate_sql() enforces length, blocks destructive ops, allows only SELECT/WITH.
core/supabase_client.py
Supabase Client
run_query() via httpx RPC. fetch_live_columns() for schema sync. Singleton client.
core/data_handler.py
Data Handler
DataFrame conversion, size classification, descriptive stats, CSV/Excel export bytes.
core/schema_sync.py
Schema Sync
Diffs live Supabase columns vs schema.json. Patches added/removed/type-changed columns on demand.
core/config_loader.py
Config Loader
Loads config.yaml once (cached). Provides LLM, data, guardrail, LangSmith, Supabase settings.
core/logger.py
Logger
get_logger(name) returns a named Python logger with stdout handler and DEBUG level.
context/schema.json
Schema Context
19-column shopping_preferences table definition with types, descriptions, and sample questions.
config.yaml
Configuration
LLM defaults, data thresholds (100/500), guardrail rules, LangSmith project name.
supabase_setup.sql
DB Setup
Creates shopping_preferences table and execute_sql RPC function required by the client.
